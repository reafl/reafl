
AI has been used for this project so far. The goal is to switch to human development once a base exists.

# Requirements

- Commit every batch of changes to git with AI: as the start of the commit message.
- Use as few input tokens as possible. Read only as much as needed for delivering full quality.
- Keep clean documented code. Any new code should be compatible with autogenerating documentation.
- Put command chains you use often into `ai_scripts/ps/**.ps1` or `ai_scripts/py/**.py`. Document those as well in the autogenerated documentation. Create a venv if necessary.
- Feel free to use any rust crates or other extensions.
- The codebase has the following priorities in order:
    1. Speed and efficiency
    2. Extendability
    3. Readability
- Feel free to split code into multiple subfiles, modules and crates.
- Feel free to replace function calls with macros where appropriate. Procedural macros are fine as well. Use the quote crate for those. Make linting and code completion possible in macros if possible.
- Keep a changelog in CHANGELOG.md.
- If useful, make use of techniques like threading and compute shaders.
